# Duplicate image review

This is a separate review and correction collection. Original Output/ and Generated_Variants/ files remain unchanged.

Scope: 6,622 workbook review rows in 1,885 exact-SHA duplicate groups. A duplicate is not automatically a mismatch.

See Reports/Progress.json for current completion and Reports/SKU_review.csv for per-SKU decisions. Pending rows have not been validated. Source metadata and catalog text are evidence, not visual approval. Automated keyword flags are prioritization only.

Corrections are stored as Category/Subcategory/Brand/SKU-V.jpg. Every AI candidate requires QC approval against exact-SKU finish, shape, text and technical details. A new path in the report proposes a replacement; it does not overwrite or approve the source. Rejected outputs are segregated in Reports/Rejected_Candidates and are not usable replacements. Earlier rejected attempts may remain there after a new candidate is produced; the per-SKU report records that history. All 1,885 groups received thumbnail screening, which is not full per-SKU technical validation. See explicit pending counts in Progress.json. No Shopify upload.
