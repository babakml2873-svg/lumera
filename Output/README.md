# Product images — all brands

**44 brands, 60,772 list SKUs.** Variant images (`SKU-V.jpg`) were delivered for **43,618 SKUs (71.8%)**, plus **36,224 gallery images** (`SKU-G-NN.jpg`).

* Variant image status: 31,947 `OK` (exact SKU, High confidence), 11,671 `OK-REVIEW-RECOMMENDED` (Medium: alias/suffix match, family/series photo or upscaled source), 17,154 SKUs without a variant image (`missing_images.csv` gives the reason for each).
* Every file is 800×800 px JPEG, ≤ 100,000 bytes, padded with its own border colour (no background removal); checked by script.
* **No Lumera Electric site, CDN or mirrored asset was used as an image source** (every URL asserted). The brand named *Lumera Electric* in the lists was sourced from the official Kuzco Group store.
* Images are third-party manufacturer/retailer photos and remain their owners' copyright.

`Reports/image_report.csv`, `missing_images.csv`, `sku_filename_mapping.csv`, `brand_progress.csv`, `review_queue.csv` (Medium-confidence and missing variant images, for manual review). Each brand ZIP holds its own subset and a README.

## Pipeline

`scripts/brands/*` harvest each source into `work/<brand>/catalog*.json`; `scripts/pipeline/run_brand.py` matches, downloads and processes; `shared_v.py` checks re-used series photos; `reports.py` validates and builds reports and ZIPs; `finish_brand.sh` commits each brand.
